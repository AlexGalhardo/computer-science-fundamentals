# Programación orientada a objetos

> English version: [README.md](README.md) · Versão em português: [README.pt-BR.md](README.pt-BR.md)

La programación orientada a objetos organiza un programa como objetos que guardan su propio estado y exponen comportamiento mediante una interfaz. Encapsulamiento, polimorfismo, herencia y composición son herramientas para controlar cómo un cambio en una parte se propaga a las demás. La mayor parte del código de negocio se escribe así, por lo que saber dónde ayudan las ideas, y dónde producen acoplamiento y code smells, importa todos los días.

## Referencias

Fuentes seleccionadas, no una lista exhaustiva. Todos los enlaces se verificaron cuando se escribió la lista.

### Empieza aquí

- [The Java Tutorials: Object-Oriented Programming Concepts](https://docs.oracle.com/javase/tutorial/java/concepts/), Oracle. Gratuito. Lección oficial corta sobre objetos, clases, herencia, interfaces y paquetes.
- [Curso de Java: Programação Orientada a Objetos](https://www.cursoemvideo.com/curso/java-poo/), Gustavo Guanabara, Curso em Vídeo. En portugués. Gratuito. Curso en video para principiantes en portugués sobre clases, encapsulamiento, herencia y polimorfismo.
- [Code Smells](https://refactoring.guru/refactoring/smells), Refactoring Guru. Gratuito. Catálogo ilustrado de smells, cada uno con sus causas y las refactorizaciones que lo tratan.

### Libros

- [Effective Java, 3rd edition](https://www.informit.com/store/effective-java-9780134685991), Joshua Bloch. De pago. Consejos concretos sobre diseño de clases, preferencia por la composición, genéricos, excepciones e inmutabilidad.
- [Refactoring, 2nd edition](https://martinfowler.com/books/refactoring.html), Martin Fowler. De pago. El libro que dio nombre a los code smells y catalogó las refactorizaciones que los eliminan.
- [Practical Object-Oriented Design, 2nd edition](https://sandimetz.com/products), Sandi Metz. De pago. El libro más legible sobre dependencias, duck typing y composición en lugar de herencia.
- [Orientação a Objetos e SOLID para Ninjas](https://www.casadocodigo.com.br/products/livro-oo-solid), Maurício Aniche, Casa do Código. En portugués. De pago. Libro corto en portugués sobre cohesión, acoplamiento y diseño de clases, una de las fuentes del quiz.
- [Think Java, 2nd edition](https://greenteapress.com/wp/think-java-2e/), Allen Downey and Chris Mayfield. Gratuito. Libro introductorio gratuito que llega a objetos, herencia y diseño de clases paso a paso.

### Cursos y clases

- [Java Programming MOOC](https://java-programming.mooc.fi/), University of Helsinki. Gratuito. Curso gratuito en dos partes con cientos de ejercicios corregidos sobre objetos, interfaces, colecciones y streams.
- [MIT 6.031 Software Construction](https://web.mit.edu/6.031/www/sp22/), MIT. Gratuito. Lecturas públicas sobre especificaciones, tipos abstractos de datos, interfaces, igualdad y mutabilidad.
- [Apostila Java e Orientação a Objetos](https://www.alura.com.br/apostila-java-orientacao-objetos), Caelum and Alura. En portugués. Gratuito. El manual gratuito en portugués usado por una generación de desarrolladores Java en Brasil.

### Artículos y especificaciones

- [The Early History of Smalltalk](https://worrydream.com/EarlyHistoryOfSmalltalk/), Alan Kay (1993). Gratuito. Quien acuñó el término explica qué se suponía que eran los objetos y los mensajes.
- [CodeSmell](https://martinfowler.com/bliki/CodeSmell.html), Martin Fowler. Gratuito. Nota corta sobre qué es un smell: una señal superficial que vale la pena investigar, no una regla.

### Documentación oficial

- [TypeScript Handbook: Classes](https://www.typescriptlang.org/docs/handbook/2/classes.html), Microsoft. Gratuito. Clases, visibilidad, clases abstractas e interfaces en el lenguaje de referencia de este repositorio.
- [The Rust Programming Language: Object-Oriented Programming Features](https://doc.rust-lang.org/book/ch18-00-oop.html), The Rust Project. Gratuito. Cómo un lenguaje sin herencia ofrece encapsulamiento y polimorfismo mediante traits.
- [Elixir: Protocols](https://hexdocs.pm/elixir/protocols.html), The Elixir Team. Gratuito. Polimorfismo en un lenguaje funcional, para comparar con interfaces y despacho dinámico.

### Videos

- [Nothing is Something](https://www.youtube.com/watch?v=OMPfEXIlTVE), Sandi Metz, RailsConf. Gratuito. Charla sobre reemplazar condicionales y herencia por composición y objetos pequeños.
- [Object-Oriented Programming is Bad](https://www.youtube.com/watch?v=QM1iUe6IofM), Brian Will. Gratuito. Una crítica bien argumentada, útil para entender los límites del paradigma.
- [Curso de POO Java](https://www.youtube.com/playlist?list=PLHz_AreHm4dkqe2aR0tQK74m8SFe-aGsY), Gustavo Guanabara, Curso em Vídeo. En portugués. Gratuito. La lista de reproducción de YouTube del curso de programación orientada a objetos en portugués mencionado arriba.
