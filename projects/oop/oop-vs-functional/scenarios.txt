# EN: Shared acceptance scenarios. Every implementation (Java, TypeScript with objects,
#     TypeScript with functions, Elixir) reads this one file and must produce these receipts.
#     All amounts are integer cents. One instruction per line, words separated by one space:
#       scenario <name>                      starts a scenario
#       item <sku> <unit price> <quantity>   adds a line to the cart
#       rule percent-coupon <code> <percent>
#       rule fixed-coupon <code> <amount>
#       rule bulk <sku> <minimum quantity> <percent>
#       rule take-pay <sku> <take> <pay>
#       tax none | tax flat <basis points>   825 basis points = 8.25%
#       expect subtotal|tax|total <amount>
#       expect discount <amount> <label>     one per applied rule, in order
#       expect error <code>                  the cart must be rejected with this code
# PT: Cenários de aceitação compartilhados. Toda implementação (Java, TypeScript com objetos,
#     TypeScript com funções, Elixir) lê este mesmo arquivo e precisa produzir estes recibos.
#     Todos os valores são centavos inteiros. Uma instrução por linha, palavras separadas por
#     um espaço. "expect discount" aparece uma vez por regra aplicada, na ordem; "expect error"
#     diz que o carrinho deve ser recusado com aquele código.
# ES: Escenarios de aceptación compartidos. Toda implementación (Java, TypeScript con objetos,
#     TypeScript con funciones, Elixir) lee este mismo archivo y debe producir estos recibos.
#     Todos los valores son centavos enteros. Una instrucción por línea, palabras separadas por
#     un espacio. "expect discount" aparece una vez por regla aplicada, en orden; "expect error"
#     indica que el carrito debe ser rechazado con ese código.
