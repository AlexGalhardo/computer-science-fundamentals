A language model does not read letters and it does not read words. It reads tokens.
A token is a piece of text with a number. The model only sees the numbers.
The tokenizer cuts the text into tokens before the model reads it, and joins the tokens back into text after the model writes.
Common words become one token. Rare words are cut into smaller pieces that the tokenizer already knows.
The word "tokenization" can be cut into "token" and "ization". The word "tokenizer" can be cut into "token" and "izer".
The pieces are learned from text. The tokenizer counts the pairs of neighbours and merges the most frequent pair.
Then it counts again and merges again. Every merge adds one token to the vocabulary.
A larger vocabulary means fewer tokens for the same text, and a smaller vocabulary means more tokens for the same text.
The model has a limit of tokens that it can read at once. The limit is called the context window.
The cost of using a model is counted in tokens too: the tokens that it reads and the tokens that it writes.
The text is stored as bytes. A letter of the English alphabet is one byte. A letter with an accent is two bytes.
A small picture such as 🙂 is four bytes. The tokenizer starts from the bytes, so it can read any text.
The model reads the tokens, the model predicts the next token, and the tokenizer turns the tokens into text again.
Learning is counting. Counting is learning. The tokenizer is learning what the text is made of.

Um modelo de linguagem não lê letras e não lê palavras. Ele lê tokens.
Um token é um pedaço de texto com um número. O modelo só enxerga os números.
O tokenizador corta o texto em tokens antes de o modelo ler, e junta os tokens de volta em texto depois que o modelo escreve.
Palavras comuns viram um token. Palavras raras são cortadas em pedaços menores que o tokenizador já conhece.
A palavra "tokenização" pode ser cortada em "token" e "ização". A palavra "tokenizador" pode ser cortada em "token" e "izador".
Os pedaços são aprendidos a partir de texto. O tokenizador conta os pares de vizinhos e funde o par mais frequente.
Depois ele conta de novo e funde de novo. Cada fusão acrescenta um token ao vocabulário.
Um vocabulário maior dá menos tokens para o mesmo texto, e um vocabulário menor dá mais tokens para o mesmo texto.
O modelo tem um limite de tokens que consegue ler de uma vez. O limite se chama janela de contexto.
O custo de usar um modelo também é contado em tokens: os tokens que ele lê e os tokens que ele escreve.
O texto é guardado em bytes. Uma letra do alfabeto inglês é um byte. Uma letra com acento são dois bytes.
Uma figurinha como 🙂 são quatro bytes. O tokenizador parte dos bytes, então consegue ler qualquer texto.
O modelo lê os tokens, o modelo prevê o próximo token, e o tokenizador transforma os tokens em texto de novo.
Aprender é contar. Contar é aprender. O tokenizador está aprendendo do que o texto é feito.
A ação, a função, a atenção e a informação terminam do mesmo jeito, e o tokenizador percebe a repetição.
The action, the function, the attention and the information end in the same way, and the tokenizer notices the repetition.
