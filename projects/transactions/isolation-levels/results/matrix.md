# Isolation level against anomaly

Generated by the tests (`docker compose run --rm ts-test`) on PostgreSQL 18.6.

| Anomaly | READ UNCOMMITTED | READ COMMITTED | REPEATABLE READ | SERIALIZABLE |
| --- | --- | --- | --- | --- |
| Dirty read | prevented | prevented | prevented | prevented |
| Non-repeatable read | **occurs** | **occurs** | prevented | prevented |
| Phantom read | **occurs** | **occurs** | prevented | prevented |
| Lost update | **occurs** | **occurs** | prevented (error 40001) | prevented (error 40001) |
| Write skew | **occurs** | **occurs** | **occurs** | prevented (error 40001) |
